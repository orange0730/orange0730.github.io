演算法課程 · 筆記 + 例題解析
+

DP 的核心是把一個大問題拆成「重疊子問題」，並靠三要素建模：狀態定義（dp[i] 代表什麼）、轉移方程（dp[i] 怎麼由前面的狀態算出來）、邊界條件（最小的子問題答案是什麼）。想清楚這三件事，程式碼往往只是把方程式翻譯成迴圈。

以經典的 0/1 背包為例：

knapsack.cpp 
// dp[j] = 容量為 j 時能拿到的最大價值
int dp[MAXW + 1] = {0};
for (int i = 0; i < n; i++)
    for (int j = MAXW; j >= w[i]; j--)   // 倒序避免重複取同一物品
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
// 答案為 dp[MAXW]

常見的錯誤是還沒想清楚「狀態要包含哪些維度」就急著寫迴圈——遇到卡關時，先回頭確認狀態定義是否漏掉了某個會影響答案的變數（例如是否用過某物品、剩餘次數等），比硬改程式碼更有效率。

並查集（Union-Find）是圖論題與連通性判斷最常用的資料結構之一：

dsu.cpp 
int par[MAXN];
void init(int n) { iota(par, par + n, 0); }
int find(int x) { return par[x] == x ? x : par[x] = find(par[x]); }
void unite(int a, int b) { par[find(a)] = find(b); }

圖論與最短路徑筆記

BFS / DFS · Dijkstra · Bellman-Ford · Floyd
+

選演算法前先問兩個問題：邊有沒有權重？沒有就用 BFS 找最短路；權重會不會是負的？會的話 Dijkstra 不適用，要換 Bellman-Ford。

dijkstra.cpp 
vector<ll> dist(n, LLONG_MAX);
priority_queue<pii, vector<pii>, greater<pii>> pq; // {距離, 節點}
dist[src] = 0;
pq.push({0, src});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;          // 已經有更短的路了，跳過
    for (auto [v, w] : adj[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
    }
}

時間複雜度 O((V + E) log V)，是目前最常用的非負權重最短路解法。

APCS 實作題解題策略

APCS 備考 · 解題思路與時間分配
+

APCS 實作題四題的配分與難度大致遞增，實務上建議的策略：

第一步：估算複雜度再動手。看到資料範圍先換算能接受的時間複雜度——n ≤ 10⁶ 通常要 O(n log n) 以內，n ≤ 10³ 才能接受 O(n²)。先算完再選演算法，可以避免寫到一半才發現會超時。

第二步：先拿部分分。第三、四題常會設計成有子任務或特殊情況分數，就算想不到滿分解法，先用暴力解拿到部分分再優化，比空白交卷划算。

第三步：邊界值自己造測資。n = 0、n = 1、全部元素相同、資料剛好等於上限，這些邊界最容易漏掉，寫完後手動帶入測試比直接送出更保險。

演算法入門課程大綱

排序 · 搜尋 · 遞迴 · 貪心 · 程式社教材
+

排序：從 Bubble Sort、Insertion Sort 理解「為什麼慢」開始，再帶到 Merge Sort（分治）與 Quick Sort（樞紐選取），比較各自的最壞情況與適用時機。

搜尋：線性搜尋 vs. 二分搜尋，重點在二分搜尋的前提（資料要已排序）與邊界寫法（left/right/mid 的收斂條件），這是最多初學者會寫出無窮迴圈的地方。

遞迴：用河內塔、費氏數列建立「相信遞迴」的直覺，再講解呼叫堆疊與記憶化如何解決重複計算問題，銜接到後面的 DP 課程。

貪心：用區間排程、找零錢等例題說明貪心成立的條件（局部最佳導致全域最佳），並舉反例說明貪心不是萬用解法。
