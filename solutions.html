新增解題心得

支援 Markdown、程式碼高亮、LaTeX（$O(n\log n)$）

管理模式

心得存在 GitHub repo 的 data/solutions.json。輸入有寫入權限的 GitHub Token 後，就能直接在這個頁面新增、編輯、刪除，儲存時會自動 commit 到 repo。

  1. 到 GitHub → Fine-grained tokens 建立新 token
  2. Repository access 選 Only select repositories → orange0730.github.io
  3. Permissions → Repository permissions → Contents: Read and write
  4. 產生後貼到下面（只會存在這台裝置的瀏覽器）
